# aaaaaaaa

> Le projet polyglotte qui dit une seule chose, mais dans beaucoup trop de langages.

```text
aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```

## Mission

Afficher exactement 100 `a`.

Pas 99.
Pas 101.
Juste:

```text
aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
```

## Regle sacree

Chaque fichier doit faire une seule chose: afficher les `a`.

Pas de framework.
Pas de logique metier.
Pas de base de donnees.
Pas de suspense.

Juste des `a`.

## Contribuer

Tu connais un langage, un dialecte, une calculatrice programmable ou un truc vaguement executable capable d'afficher du texte ?

Il est probablement eligible.

Conditions d'entree:

1. Le fichier affiche les 100 `a`.
2. Le fichier reste minimal.
3. Le nom du fichier reste compose de 8 `a`.
4. L'extension sert a reconnaitre le langage.
